📝 Cara Membuat Icon PWA:

  1. Gunakan PWA Builder (Paling Mudah):
    → Kunjungi https://www.pwabuilder.com/imageGenerator
    → Upload gambar 512x512px
    → Download semua ukuran
  2. Gunakan Canva (Gratis):
    → Buat desain 512x512px
    → Background gradient ungu-pink
    → Tambahkan emoji 💸 atau text
    → Export dan resize ke berbagai ukuran
  3. Gunakan Figma/Photoshop:
    → Desain custom 512x512px
    → Export ke PNG
    → Resize ke ukuran yang dibutuhkan
  4. Simpan semua icon ke folder icons/ dengan nama:
    icon-72.png, icon-96.png, icon-128.png,
    icon-144.png, icon-152.png, icon-192.png,
    icon-384.png, icon-512.png
