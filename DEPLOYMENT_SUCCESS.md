## 🖼️ Icon PWA (Belum Ada)

Aplikasi sudah live, tapi **icon PWA belum dibuat**.

### Cara Buat Icon:

**Opsi 1: PWA Builder (Recommended)**
1. Buka: https://www.pwabuilder.com/imageGenerator
2. Upload gambar 512x512px
3. Download semua ukuran
4. Rename sesuai format:
   - icon-72.png
   - icon-96.png
   - icon-128.png
   - icon-144.png
   - icon-152.png
   - icon-192.png
   - icon-384.png
   - icon-512.png
5. Simpan ke folder `icons/`

**Opsi 2: Gunakan icon-generator.html**
1. Buka `icon-generator.html` di browser
2. Klik "Download Preview Icons"
3. Simpan semua ke folder `icons/`

### Setelah Icon Dibuat:

```bash
# Add icon files
git add icons/

# Commit
git commit -m "Add PWA icons"

# Push
git push
```
