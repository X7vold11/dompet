# PWA Icons

Folder ini berisi icon untuk Progressive Web App.

## Icon yang Dibutuhkan

Buat icon dengan ukuran berikut:
- icon-72.png (72x72)
- icon-96.png (96x96)
- icon-128.png (128x128)
- icon-144.png (144x144)
- icon-152.png (152x152)
- icon-192.png (192x192)
- icon-384.png (384x384)
- icon-512.png (512x512)

## Cara Membuat Icon

### Opsi 1: Gunakan PWA Builder
1. Kunjungi https://www.pwabuilder.com/imageGenerator
2. Upload logo/icon 512x512px
3. Download semua ukuran
4. Simpan di folder ini

### Opsi 2: Gunakan RealFaviconGenerator
1. Kunjungi https://realfavicongenerator.net/
2. Upload logo/icon
3. Generate dan download
4. Simpan di folder ini

### Opsi 3: Buat Manual dengan Canva/Figma
1. Buat desain 512x512px dengan background solid
2. Tambahkan emoji 💸 atau logo custom
3. Export dalam berbagai ukuran
4. Simpan di folder ini

## Rekomendasi Desain

- **Background**: Gradient ungu (#7C3AED) ke pink (#EC4899)
- **Icon**: Emoji 💸 atau ilustrasi dompet
- **Style**: Rounded corners, modern, clean
- **Format**: PNG dengan transparency (jika perlu)
